# Nexa — Replacement Notes

این نسخه بدون اضافه کردن هیچ dependency جدیدی آماده شده است.

- `package.json` تغییر نکرده و dependency جدیدی اضافه نشده.
- CDN مربوط به Tailwind از `nuxt.config.ts` حذف شد؛ Nuxt UI/Tailwind موجود پروژه استفاده می‌شود.
- پوسته روشن/تیره و رنگ پس‌زمینه اصلاح شد.
- داشبورد، وظایف، برنامه‌ریز، یادگیری، اهداف، پروژه‌ها، تمرکز و تنظیمات تعاملی‌تر شدند.
- داده‌های اصلی در `data/nexa.json` ذخیره می‌شوند و در LocalStorage مرورگر نگهداری نمی‌شوند.
- تایمر Focus با timestamp کار می‌کند و با تغییر tab زمانش خراب نمی‌شود.
- خروجی JSON و CSV برای داده‌های محلی اضافه شده است.
- جستجوی سریع صفحات با `Ctrl + K` اضافه شده است.
- طراحی responsive و RTL بازطراحی شده است.

بعد از جایگزینی فایل‌ها، در صورت وجود `node_modules` فعلی، نصب پکیج جدید لازم نیست.
