# Nexa Productivity OS — نسخه بازطراحی تجربه کاربر

این نسخه با سناریوی واقعی **DATA → PLAN → EXECUTE → RECORD → ANALYZE → FEEDBACK** بازطراحی شده است.

### سناریوی اصلی
1. کاربر کارها را می‌سازد و برایشان تاریخ، ساعت، مدت، پروژه و هدف تعیین می‌کند.
2. کارهای پرتکرار در لیست کارها می‌مانند و برای روزهای بعد فقط تاریخ/زمان آن‌ها تغییر می‌کند یا کار جدید از روی همان الگو ساخته می‌شود.
3. برنامه‌ریز سناریوی هر روز را نگه می‌دارد و کارها را به بلوک زمانی وصل می‌کند.
4. صفحه «امروز» مرکز اجراست: زمان فعلی، کار جاری، کار بعدی و کارهای عقب‌افتاده را نشان می‌دهد.
5. با «اجرا» تایمر به همان کار وصل می‌شود. تایمر timestamp-based و persistent است و refresh آن را صفر نمی‌کند.
6. پایان جلسه، زمان واقعی را ثبت می‌کند و کار/برنامه/تحلیل را به‌روز می‌کند.
7. اعلان مرورگر برای پایان تایمر، نزدیک شدن زمان برنامه و پیام انگیزشی اختیاری است.
8. گزارش کار با قالب قابل تنظیم تولید، نمایش و در تاریخچه ذخیره می‌شود.
9. تحلیل‌ها از داده واقعی کارها، تایمرها، اجرای برنامه و اهداف ساخته می‌شوند.

### داده
تمام داده‌های اصلی در localStorage مرورگر ذخیره می‌شوند و با refresh باقی می‌مانند. خروجی JSON برای backup در Settings موجود است.

### اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000`

### نکته
اعلان سیستم‌عامل به قابلیت‌های مرورگر و permission کاربر وابسته است. اگر مرورگر بسته باشد، اجرای JavaScript تضمین‌شده نیست؛ PWA این محدودیت را دور نمی‌زند.
