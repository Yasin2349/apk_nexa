# Nexa Android — نسخه اصلاح‌شده برای تست

این پروژه یک پوسته اندرویدی WebView برای نسخه فعلی Nexa است. رابط موبایل از طریق CSS اختصاصی تزریق‌شده در `MainActivity.kt` بهینه شده است تا راست‌چین، خوانا و مناسب لمس باشد.

## ساخت APK با GitHub Actions
1. محتویات این پوشه را در ریشه مخزن GitHub خود قرار دهید.
2. از تب Actions، workflow با نام `Build Nexa Android APK` را اجرا کنید.
3. پس از موفقیت workflow، Artifact با نام `Nexa-Android-APK` را دانلود کنید؛ فایل `app-debug.apk` داخل آن است.

## مهم
این نسخه در محیط حاضر روی دستگاه واقعی Android اجرا نشده و APK نهایی از اینجا تأیید نشده است. ابتدا workflow را اجرا و سپس روی گوشی بررسی کنید. این پوسته از کد وب موجود استفاده می‌کند؛ اصلاحات رابط موبایل به‌تنهایی تضمین نمی‌کند همه قابلیت‌های native مانند تایمر پس‌زمینه بدون آزمون عملی کار کنند.
