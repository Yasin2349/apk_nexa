# Nexa Android — نسخه قابل نصب

این پروژه یک اپ اندروید با رابط Nexa فعلی و لایه Native برای تایمر، اعلان پایان تایمر و ویجت صفحه اصلی است. داده‌ها روی خود گوشی و در WebView ذخیره می‌شوند؛ برای استفاده روزمره به VPS نیاز ندارد.

## ساخت APK

**در این محیط Android SDK/Gradle نصب نیست، بنابراین APK از قبل کامپایل نشده است.** سورس Android Studio آماده است:

1. Android Studio را نصب و باز کن.
2. از **Open** پوشه `Nexa-Android` را انتخاب کن.
3. اگر Android SDK Platform 35 و Build Tools را خواست، از SDK Manager نصب کن.
4. صبر کن Gradle Sync تمام شود.
5. از منو **Build → Build APK(s)** را بزن.
6. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

برای نصب روی گوشی، APK را به گوشی منتقل و باز کن. اگر گوشی اجازه نصب از این منبع را خواست، فقط برای همان منبع اجازه بده.

## قابلیت‌ها

- رابط فعلی Nexa به‌صورت محلی در WebView بسته‌بندی شده است؛ VPS برای استفاده عادی لازم نیست.
- داده‌های شروع اولیه خالی هستند و نمونه‌های نمایشی در اولین اجرا به کاربر تحمیل نمی‌شوند.
- نوار ناوبری پایین مخصوص موبایل.
- اعلان پایدار تایمر فعال و هشدار پایان تایمر از طریق AlarmManager.
- درخواست مجوز اعلان و دسترسی آلارم دقیق در نسخه‌های اندروید مربوطه.
- ویجت صفحه اصلی برای نمایش تایمر فعال یا نزدیک‌ترین کار امروز.
- پس از reboot، برنامه تلاش می‌کند تایمر در حال اجرا را از وضعیت ذخیره‌شده بازیابی کند.

## نکات مهم HyperOS

برای تحویل هشدار دقیق‌تر، مجوز اعلان و آلارم را تأیید کن. اگر HyperOS برنامه را در پس‌زمینه محدود کرد، از تنظیمات باتری گوشی برای Nexa حالت **No restrictions / بدون محدودیت** و در صورت موجود بودن Autostart را فعال کن. نام دقیق گزینه‌ها به نسخه HyperOS وابسته است.

## محدودیت فعلی

این بسته سورس کامل Android Studio و وب‌اپ کامپایل‌شده داخل assets را دارد، اما APK نهایی در این محیط تولید نشده چون Android SDK در دسترس نیست. ویجت برای نمایش وضعیت و بازکردن اپ است؛ کنترل‌های تعاملی پیشرفته روی ویجت و کاشی Quick Settings در این نسخه پیاده‌سازی نشده‌اند.


## روش کم‌نصب برای ساخت APK با GitHub Actions

نیازی به نصب Android Studio یا Android SDK روی کامپیوتر نیست؛ GitHub روی سرورهای خودش APK را می‌سازد.

1. در GitHub یک repository خصوصی جدید بساز.
2. محتوای پوشه `Nexa-Android` را داخل repository آپلود کن (خود فایل ZIP را به‌عنوان تنها فایل آپلود نکن؛ باید فایل‌ها و پوشه‌ها استخراج شده باشند).
3. در تب **Actions**، workflow با نام **Build Nexa Android APK** را باز کن.
4. اگر لازم بود **Run workflow** را بزن. پس از پایان موفق، اجرای workflow را باز کن.
5. در پایین صفحه بخش **Artifacts**، فایل `Nexa-Android-APK` را دانلود کن و ZIP آن را باز کن؛ داخلش `app-debug.apk` است.

این کار در فضای ابری انجام می‌شود و چیزی سنگین روی ویندوز نصب نمی‌کند. اگر build شکست خورد، متن خطای بخش Build را بررسی کن؛ وجود workflow به‌تنهایی تضمین نمی‌کند که پروژه بدون خطا کامپایل شود.
